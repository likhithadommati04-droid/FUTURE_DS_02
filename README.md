# FUTURE_DS_02

## Project Overview
This project focuses on analyzing customer churn and retention patterns for a subscription-based business. The objective is to identify churn behavior, understand retention drivers, and provide actionable business recommendations using data analytics techniques.

## Internship Details
* Internship Domain: Data Science & Analytics
* Organization: Future Interns
* Task Number: Task 2
* Project Title: Customer Retention & Churn Analysis

## Objectives
* Analyze customer churn patterns
* Identify high-risk customer groups
* Study retention trends
* Calculate Customer Lifetime Value (CLV)
* Generate business insights and recommendations

## Tools & Technologies Used
* Python
* Pandas
* Matplotlib
* Jupyter Notebook
* Excel / Power BI (Optional)

## Dataset Information
The dataset includes:
* Customer ID
* Gender
* Age
* Contract Type
* Monthly Charges
* Tenure
* Payment Method
* Churn Status

## Key Analysis Performed
### Churn Rate Analysis
Calculated the percentage of customers who discontinued the service.

### Contract Type Analysis
Compared churn behavior across:
* Month-to-Month Contracts
* One-Year Contracts
* Two-Year Contracts

### Tenure Analysis
Analyzed how customer duration impacts retention.

### Payment Method Analysis
Identified payment methods associated with higher churn.

### Customer Lifetime Value (CLV)
Estimated long-term revenue generated from customers.

## Key Insights
* Month-to-month customers have the highest churn rate.
* Customers with high monthly charges are more likely to churn.
* New customers are at greater risk during the initial months.
* Long-term contracts improve customer retention.
* Electronic check users show higher churn behavior.

## Business Recommendations
1. Offer discounts for long-term subscriptions.
2. Improve onboarding support for new customers.
3. Introduce customer loyalty programs.
4. Enhance customer support services.
5. Use predictive analytics for early churn detection.
